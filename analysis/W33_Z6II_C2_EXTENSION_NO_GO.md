# W33 / Z6-II order-two comparison: exact no-go

The current cyclic Z6-II point group is C6 = C3 x C2. If theta generates C6, then theta^2 generates C3 and theta^3 generates C2, and

`theta^3 theta^2 theta^-3 = theta^2`.

So the heterotic order-two point-group factor acts **trivially** on the order-three subgroup. The order-two Wilson line is an Abelian gauge-lattice shift and does not change that extension law.

The W33 outer involution instead satisfies `s z s^-1 = z^-1` on the Heisenberg center C3, hence generates `C3:C2 = S3`.

Therefore the two C2 actions are not equivariantly identifiable. A genuine heterotic analogue would need a non-Abelian S3/dihedral-type extension with an inversion reflection. This note prevents the earlier cross-repo analogy from being promoted beyond what the group laws support.
